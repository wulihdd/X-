# X 中文油猴脚本插件

一个用于 X（原 Twitter）网页版的油猴脚本，将常见英文界面文字显示为简体中文。

浏览器原生翻译有时不够方便，因此制作了这个脚本。

## 安装

1. 在浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 点击 **[安装 X 中文油猴脚本插件](https://github.com/wulihdd/X-/raw/main/x.user.js)**，在脚本管理器中确认安装。
3. 打开或刷新 [X 网页版](https://x.com/)。

如果没有出现安装页面，可以新建油猴脚本，将本仓库中 `x.user.js` 的全部内容复制进去并保存。

## 功能与说明

- 翻译导航、设置、通知、个人资料、分析、创作者工具等页面中的部分常见界面文字。
- 使用脚本内置词条，不调用翻译 API；未收录的文案会保留原文。
- 不自动翻译帖子正文或私信内容，不修改用户填写的内容。
- X 的界面可能随时变化，个别文案或与其他扩展的兼容性可能需要后续调整。欢迎通过 GitHub Issues 反馈问题。

## 更新

项目将**不定时更新**。脚本内已配置版本号、更新检查地址和下载地址，篡改猴可检查 GitHub 上的新版本。

1. 通过上方安装链接安装本脚本；之前手动创建的旧版脚本如仍启用，请将旧版关闭，避免重复运行。
2. 在篡改猴的设置中开启脚本更新检查，并确保本脚本的更新检查没有被关闭。
3. 如果希望先看到更新再决定是否安装，请在篡改猴的脚本更新设置中检查“自动安装”和更新通知选项。具体提示方式取决于篡改猴版本和个人设置。
4. 也可以在篡改猴中手动检查更新，或回到本仓库重新安装。

维护者发布更新时，应提高 `x.user.js` 头部的 `@version`，并将新版本提交到同一文件路径，否则脚本管理器可能无法识别新版本。原来的中文文件名链接保留用于兼容旧版，新安装和后续更新请使用 `x.user.js`。
